# SmartFlix - Movie Recommendation System

SmartFlix is a personalized movie recommendation system built using collaborative filtering and matrix factorization.

## Overview

The system analyzes movie-rating data to generate personalized movie recommendations using collaborative filtering techniques. Multiple recommendation approaches are evaluated to identify the most effective model.

## Features

- Personalized movie recommendations
- Collaborative filtering
- Matrix factorization using SVD
- Comparison with baseline recommendation models
- Interactive Streamlit interface
- LLM-assisted recommendation validation

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- Surprise
- Streamlit
- Google Gemini API

## Model

The recommendation pipeline uses Singular Value Decomposition (SVD) for matrix factorization and evaluates its performance against baseline approaches using RMSE.

## Results

The SVD-based recommendation model achieves an RMSE of approximately 1.082 on the evaluation dataset.
